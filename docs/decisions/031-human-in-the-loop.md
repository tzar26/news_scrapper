# ADR-031: Human-in-the-loop (Ручная корректировка Market Impact)

Дата: 2026-11-12
Статус: внедрено (Приватная ветка `private/trading`)

## Контекст

LLM (Qwen) не всегда идеально определяет тональность новости. Возможны ошибки: сарказм, сложный контекст («снижение прибыли, но лучше ожиданий»), или просто галлюцинации. Если трейдер видит, что новость оценена неверно, он должен иметь возможность исправить это, чтобы сигнал пересчитался.

## Решение

Внедрить механизм Human-in-the-loop (человек в контуре) на странице Signals.

### 1. Хранение правок в БД
В модель `Article` добавлены поля:
- `is_manually_edited` (Boolean): флаг, что статью правил человек.
- `manual_impact_direction` (String): направление, которое указал человек (`bullish`, `bearish`, `neutral`).

Эти поля позволяют отделить «мнение LLM» от «мнения человека». При сборке ML-датасета приоритет отдается `manual_impact_direction`.

### 2. API (PATCH /articles/{id}/impact)
Создан эндпоинт для ручного обновления тональности. Он:
1. Валидирует `direction`.
2. Обновляет `is_manually_edited` и `manual_impact_direction` (а также дублирует в `market_impact.direction` для совместимости).
3. Сбрасывает кеш сигналов (Redis) для всех тикеров, связанных с этой статьей, чтобы сигналы пересчитались.

### 3. UI (Streamlit)
В карточке каждой новости (внутри `st.expander`) добавлены три кнопки: 🟢 Bullish, 🔴 Bearish, ⚪ Neutral.
При нажатии:
1. Вызывается API.
2. Очищается кеш Streamlit (`st.cache_data.clear()`).
3. Страница перезагружается (`st.rerun()`).

*Важно:* Ключи кнопок сделаны уникальными (`bull_{ticker}_{article_id}`), чтобы избежать ошибки `StreamlitDuplicateElementKey`, если одна и та же новость появляется в сигналах разных тикеров.

### 4. Влияние на обучение
Ручные правки влияют на будущее обучение модели. При переобучении `build_ml_dataset.py` будет использовать `manual_impact_direction` (если `is_manually_edited = True`).

**Порог для переобучения:** Рекомендуется переобучать модель после накопления **50+ ручных исправлений** (или если правки затрагивают >10% датасета). До этого правки влияют только на текущие сигналы, но не на модель.

## Ограничения
Ручная правка меняет impact для всей статьи (всех тикеров). В будущем планируется per-ticker impact

## Последствия

- Трейдер получает контроль над качеством данных.
- Мы собираем статистику: сколько статей исправлено, какие типы ошибок чаще всего допускает LLM.
- В будущем можно использовать эти данные для дообучения (Fine-tuning) модели Qwen.
