# ADR-025: Концепция развития Vision 2.0 (Стратегические треки)

Дата: 2026-11-06
Статус: план (Приватная ветка `private/trading`)

## Контекст

После запуска базового ML-пайплайна (PoC RandomForest, `market_pressure`, `news_count`) мы упёрлись в потолок Accuracy ~0.48 на малых данных (55 записей). Чтобы превратить проект в полноценный аналитический инструмент (и подготовить базу для будущих статей/презентаций инвесторам), необходимо зафиксировать стратегическое видение развития.

Мы выделяем три трека: **Quick Wins** (можно сделать на текущих данных), **Core R&D** (требуют накопления данных и новых источников) и **Moonshot** (исследовательские фичи для будущего).

## Решения

### Трек 1: Quick Wins (Реализуемо на текущих данных)

1. **Volume Anomaly (Аномалии объёма)**
   - *Идея:* Резкий скачок объёма торгов часто предшествует движению цены (вход/выход крупного игрока).
   - *Реализация:* Фича `volume_ratio = volume / ADV_20d`. Флаг `is_volume_anomaly = volume_ratio > 3.0`.
   - *Данные:* Свечи MOEX (уже есть).
   - *Сложность:* S.
   - *Примечание:* Прямой «переход контроля» через API Мосбиржи не получить (ISS не раскрывает контрагентов). Поэтому используем эвристику аномального объёма. Для реальных сделок M&A — парсинг E-disclosure (отложено).

2. 3. **Corporate Actions Extraction (Buyback / SPO)**
   - *Статус:* **Проверено.** В базе 113 заголовков с ключевыми словами. Данных достаточно.
   - *Проблема:* SQL-поиск по `%SPO%` ловит "Sports", `%выкуп%` ловит "выкуп облигаций".
   - *Решение (LLM-based Extraction):*
     Внедрить в пайплайн легковесный шаг `extract_corporate_action` (можно параллельно с NER).
     Промпт для Qwen классифицирует новость по схеме:
     - `action_type`: `buyback` | `spo` | `dividend` | `none`
     - `target_ticker`: тикер (из NER)
     - `is_valid`: bool (выкуп именно акций, а не облигаций/долей)
     - `market_impact_direction`: `bullish` (buyback) / `bearish` (spo)
   - *Сложность:* M (нужно написать и протестировать промпт).
   - *Ценность:* Прямой сигнал для трейдера (например, "Т-Технологии выкупают Циан — бычий сигнал").

3. **Expected Return (E[return]) + Risk/Reward**
   - *Идея:* Трейдеру нужна не только вероятность `P(up)`, но и ожидаемая доходность.
   - *Реализация:* Добавить регрессионную голову (или отдельную модель) для предсказания `E[return]`. В API отдавать `P(up)`, `E[return]` и `Risk/Reward = P(up) * E[return] / (1 - P(up))`.
   - *Данные:* Текущий ML-датасет.
   - *Сложность:* S.

### Трек 2: Core R&D (Требуют данных и новых источников)

4. **Event Horizons (Прогноз горизонта выхода / Take Profit)**
   - *Идея:* Разные события (геополитика, макро, корпоративные) отыгрываются рынком за разное время. Нужно предсказывать не только «куда», но и «когда выходить».
   - *Реализация:*
     1. Классификатор типа события (`geopolitics`, `macro`, `corporate`, `sectoral`).
     2. Расчет исторического распределения «горизонта отыгрыша» (дней до пика/разворота) для каждого типа.
     3. API: `expected_holding_period`.
   - *Зависимость:* Нужно минимум 100–200 событий на каждый тип.
   - *Сложность:* L.
   - *Примечание:* Это прямой ответ на запрос «когда фиксировать прибыль».

5. **Global Risk Factor (Влияние мирового фона)**
   - *Идея:* Российский рынок коррелирует с глобальными индексами (S&P 500, VIX) и сырьём (Brent).
   - *Реализация:* Добавить фичи `global_vix`, `sp500_return`, `brent_return`. Новые источники: Yahoo Finance (через `yfinance`).
   - *Данные:* Нужны исторические данные по глобальным индексам.
   - *Сложность:* M.
   - *Примечание:* API Мосбиржи даёт только российские инструменты. Глобальные новости — отдельный парсер (Reuters/Bloomberg — сложно, начинаем с Yahoo Finance).

### Трек 3: Moonshot (Исследовательские фичи)

6. **Fragility Score / Black Swans (Чёрные лебеди)**
   - *Идея:* Чёрного лебедя предсказать нельзя (Талеб), но можно детектировать «хрупкость» — расхождение между новостным фоном и реакцией цены.
   - *Реализация:* `fragility_score = |market_pressure| - |normalized_price_change|`. Если новости сильно направленные, а цена стоит — накопление риска.
   - *Сложность:* L (требует валидации гипотезы).
   - *Примечание:* Идеально для раздела «Vision» в презентации инвесторам.

## Последствия

- Мы четко разделяем «что делаем сейчас» (Quick Wins) и «куда движемся» (R&D/Moonshot).
- Это позволяет не распылять ресурсы и честно говорить инвесторам/трейдерам: «Вот что работает, вот что в разработке, вот наше видение».
- ADR-024 (смешанные сигналы) остается в силе: ждем 200+ записей для внедрения фичей доминирования.

## Отложенные эксперименты (из ADR-020)

- **Ablation study:** Сравнить окна Walk-Forward (7/30/90 дней).
- **Lag Test:** Проверить деградацию модели при задержке новостей на 1-2 дня.
- **Time Decay:** Вернуться при 200+ записей (как отдельная фича `weighted_impact`).
