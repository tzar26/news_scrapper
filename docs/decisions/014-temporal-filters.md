# ADR-014: Временные фильтры (days_ago)

Дата: 2026-10-20
Статус: принято

## Контекст

Пользователям нужны не просто релевантные статьи, а актуальные новости (за 1, 3, 7 дней) для краткосрочного прогнозирования рынка.

## Решение

Ввести параметр `days_ago: int | None` во все слои поиска:
1. **Retriever**: Добавление `published_at >= cutoff` в оба метода (vector и BM25).
2. **API**: Параметр `days_ago` в `AskRequest` и `SearchRequest`.
3. **UI (Streamlit)**: Селектор периода ("Всё время", "За 1 день", "За 3 дня", "За 7 дней").
4. **Agent (LangGraph)**: Добавление `days_ago` в схему инструмента `search_articles`. В PLANNER_PROMPT добавлена инструкция для LLM извлекать временной период из вопроса пользователя ("за последние 2 дня" → `days_ago=2`).

## Последствия

- Поиск и RAG работают только по свежим данным, если выбран период.
- LangGraph-агент успешно справляется с zero-shot извлечением периода из запроса (подтверждено логами).
