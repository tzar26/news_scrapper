# ADR-016: Sentiment Analysis — ограничения применимости для рынка

Дата: 2026-10-27
Статус: принято (отключено в аналитике)

## Контекст

Мы внедрили извлечение тональности (positive/neutral/negative) через LLM (Qwen 2.5 14B) и добавили инструмент `get_sentiment` для агента, который считал индекс от -100 до +100 для категорий.

## Проблемы (выявлены при валидации датасета)

При ручной проверке выборки выяснилось, что классический подход Sentiment Analysis плохо применим для новостной и финансовой аналитики:

1. **Субъективность геополитики.** Новость «Украина теряет поддержку» модель оценила как `negative`, хотя для российского инвестора это может быть позитивом. Модель оценивает эмоциональную окраску конфликта, а не рыночный эффект.
2. **Шум и несущественность.** Статьи про локальные преступления или нарушения границ попадают в `negative` и `conflicts`, хотя не имеют никакого значения для фондового рынка.
3. **Противоречие бизнес-цели.** Для трейдинга нужна метрика «влияние на котировки» (Market Impact), а не эмоциональная окраска текста.

## Решение

1. **Отключаем инструмент `get_sentiment` у LangGraph-агента.** Агент не будет использовать эту метрику для ответов.
2. **Оставляем код и извлечение в БД** (поле `sentiment`) как справочную информацию, но не используем для агрегации и аналитики.
3. **Не тратим ресурсы на ручную валидацию** этой метрики (она не критична для продукта).
4. В будущем, если понадобится аналитика настроений, переходим на **Financial Sentiment** (модели, обученные на котировках) или **Market Impact** (классификация влияния на цену), а не на общий NLP.

## Вывод

Отрицательный результат — тоже результат. Мы сэкономили ресурсы, вовремя распознав, что стандартная метрика не работает для доменной задачи. Это классический пример Data-Centric AI: качество данных и бизнес-логика важнее алгоритмов.

## Уточнение по NER

**NER (Named Entity Recognition) признан полезным и остается в системе.**
Инструмент `search_by_entity` (поиск статей по компаниям/персонам) продолжает работать.
Отключается только агрегация эмоциональной окраски (Sentiment Index), так как она не коррелирует с влиянием на рынок.
