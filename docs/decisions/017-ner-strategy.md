# ADR-017: Стратегия извлечения сущностей (NER)

Дата: 2026-10-27
Статус: принято

## Контекст

Для аналитики (поиск по компаниям, оценка влияния на рынок) нам нужно извлекать из текста компании (ORG), персоны (PER) и локации (LOC).

## Рассмотренные варианты

### Путь А: Zero-Shot LLM (Qwen 2.5 14B) — ВЫБРАН
Плюсы: Единый стек (всё через Ollama), понимание контекста, легко менять промпт.
Минусы: Может пропускать редкие аббревиатуры (ВСУ), иногда тащит лишнее (спортивные союзы).
Решение: Мы ужесточили промпт, явно указав, что игнорировать (суды, соревнования), и сфокусировались на экономически значимых сущностях.

### Путь Б: Специализированные NLP-библиотеки (spaCy / Natasha) — ОТЛОЖЕН
Плюсы: В 100 раз быстрее, находит все аббревиатуры по словарю, не галлюцинирует.
Минусы: Не знает новых компаний (без дообучения), требует отдельного пайплайна (не через LLM).
Решение: Оставляем как запасной вариант. Если NER через LLM начнет давать сбои на больших объемах, мы перейдем на spaCy (`ru_core_news_lg`) и будем использовать LLM только для сложных случаев.

## Текущее решение

Используем LLM (Qwen) с жестким промптом. Поле `entities` в JSONB хранит массив `{"text": "...", "type": "ORG|PER|LOC"}`.
