# ADR-018: Оценка влияния на рынок (Market Impact)

Дата: 2026-10-28
Статус: принято

## Контекст

Классический Sentiment Analysis (positive/negative/neutral) показал свою несостоятельность для финансовой аналитики (см. ADR-016). Он оценивает эмоциональную окраску, а не влияние на рыночные активы.

## Решение

Ввести метрику **Market Impact** (Влияние на рынок) через LLM (Qwen 14B).

**Схема JSON (поле `market_impact` в БД):**
```json
{
  "type": "event",           // "event" (конкретное событие) или "overview" (обзор)
  "target_market": "ru",     // "ru", "us", "eu", "global"
  "importance": "high",      // "high" (весь рынок), "medium" (компания), "low" (шум)
  "main_sector": "energy",   // Главный сектор (только один)
  "direction": "bullish"     // "bullish", "bearish", "neutral"
}

## Ключевые особенности промпта

1. Контекст: «Ты — трейдер на российском фондовом рынке».
2. Фильтр type: обзорные статьи (дайджесты) не влияют на рынок.
3. Фильтр importance: локальные новости (спорт, погода) получают low и отсекаются.
4. Главный сектор: модель выбирает только один самый значимый сектор (избегаем «размазывания» позитива на всё).

### Результат

Агент получил инструмент get_market_impact, который агрегирует количество High-событий по секторам за N дней.
Пример ответа: «В фокусе сектор технологий (2 важных события, позитивный тренд)».

### Ограничения

Модель 14B иногда переоценивает масштаб локальных новостей.
Для обзорных статей (SmartLab) модель может ставить event, но фильтр importance: low отсеивает их в аналитике.
